UI Tests (Playwright)

Record a test

Define a test by recording browser actions with Playwright Codegen, then paste the generated code here.

View all test runs (API and UI) in Test Runs in the navigation.

Add recorded test

Use Playwright Codegen to record browser interactions. Click "Launch Codegen" to open the browser and Inspector automatically, or copy the command to run it manually in a terminal.

For more information, view the documentation at https://playwright.dev/docs/intro.

Example — what you can record

Access page https://www.meo.pt/empresas/ and search for text "connect" and click it. Codegen will generate code like:

import { test, expect } from '@playwright/test';

test('test', async ({ page }) => {
  await page.goto('https://www.meo.pt/empresas');
  await page.getByRole('button', { name: 'CONCORDO' }).click();
  await page.getByLabel('Navegação principal').getByRole('menuitem', { name: 'Connect' }).click();
});
Placeholders such as ${suffix} can be edited here and are resolved at run time from the selected UI Test Variable group.
